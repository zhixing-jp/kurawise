1. 入门：基本流程

在主页选择“想做什么”后，每个画面只显示一个步骤的说明。只需点按“下一步”即可完成。

  1. 选择来源（iPhone、SD 卡、文件夹等）
  2. 确认内容（全部导入，或查看内容后选择）
  3. 选择保存位置文件夹（也可选择上次的保存位置）
  4. 选择文件夹的划分方式（年 / 月、年 / 月 / 日、含地名）
  5. 确认后开始。使用“试运行”，可以不实际复制、仅查看结果
已导入的照片会自动跳过，同一设备多次导入也不会重复。导入完成后，会自动检查来源中的照片是否已全部保存到保存位置，并在完成画面顶部显示结果。

处理期间 Mac 不会进入睡眠，同时也可以使用其他 App。完成后会通过通知告知您。

2. 从 iPhone 或 iPad 导入

  1. 用数据线将 iPhone 连接到 Mac，并解锁。
  2. 出现“要信任此电脑吗？”时，选择“信任”。
  3. 选择显示的 iPhone 即可读取内容，同时会显示与保存位置相比“未导入 N 个”。
  • 实况照片（照片与视频的组合）和编辑信息（.AAE）会原样导入。
  • 如需以 HEIC 格式导入，请将 iPhone 的“设置 › App › 照片 › 传输到 Mac 或 PC”设为“保留原片”。
  • 即使数据线松脱，重新连接后也可通过“继续导入”继续。导致多次中断的文件会被自动取消选择。
  • 照片较多时需要一些时间。不通过 USB 扩展坞、直接连接 Mac 会更快更稳定。

3. 从外部存储导入

设备连接方法与注意事项
SD、microSD、CF 卡插入读卡器（microSD 请使用转接卡）。读取期间请勿拔出。
数码相机取出 SD 卡并用读卡器读取最快也最可靠。如通过 USB 连接，请打开相机电源，并将 USB 模式设为“PC 连接”“PTP”等。
Android 手机通过 USB 连接并解锁手机，在通知的“USB 设置”中选择“传输照片（PTP）”。“文件传输”模式下 Mac 无法识别。仅存在于 Google 相册中的照片无法导入，请先保存到手机。
U 盘、外置磁盘直接连接即可。支持 APFS、Mac OS 扩展、exFAT、FAT32、NTFS（只读）。
NAS、网络文件夹先在访达中连接，再通过“选择其他位置…”选择。

拔出前，请先在访达中点按“推出”。

支持的文件格式

  • 照片：HEIC、JPEG、PNG、TIFF、GIF、WebP、AVIF、JPEG XL，以及主流相机的 RAW（DNG、CR2/CR3、NEF、ARW、RAF、ORF、RW2、PEF、SRW、3FR、IIQ 等）
  • 视频：MOV、MP4、M4V、3GP、AVI、MTS/M2TS、MKV、WebM、MPG、WMV、MXF 等
  • 一并处理的附属文件：iPhone 的编辑信息（.AAE）、Lightroom 等的冲印设置（.XMP）。会与同名照片一起复制或移动

拍摄日期从照片的 Exif 和视频的拍摄日期中读取。无法读取的格式，将使用文件创建日期与修改日期中较早的一个。

4. 整理 Mac 文件夹

  • 复制并整理（推荐）：按“年/月”复制到其他文件夹。原始文件保持不变。
  • 在此文件夹内整理：在该文件夹内移动到“年/月”文件夹，不会增加占用空间。之后可通过“撤销”（⌘Z）恢复整理前的状态。

“照片”App 的图库请使用“从照片图库导入”。

5. 从照片图库导入

将 Mac“照片”App 中的照片和视频原片导出到普通文件夹并整理。首次使用时会询问是否允许访问照片图库，请选择“允许”。

  • 不会更改或删除图库中的照片。
  • 编辑过的照片可选择“仅原片”“仅编辑后”或“两者”。也可以按相簿选择。
  • 原片仅存于 iCloud 的照片，会在导入时通过“照片”App 自动下载（了解详情）。

6. 重复检查

选择文件夹后，会查找相同的照片以及仅大小或格式不同的副本。查找方式可选“完全相同”“几乎相同”（转换或缩小的副本）“相似照片”（连拍等）。

  • ⭐ 表示建议“保留的那一张”（画质最好的）。点按即可更改。
  • 合并：将保留的那一张以外的照片移到“重复文件”文件夹。删除：移到废纸篓。
  • 两种方式之后都可以通过“撤销”放回原处。

7. 遗漏检查

按月检查所连接设备中的照片和视频是否已全部导入保存位置，并生成报告。推荐在从 iPhone 删除照片前用作备份检查。仅检查，不会更改任何文件。

  1. 打开主页中的“遗漏检查”。
  2. 选择要检查的设备和保存位置（导入的文件夹）。
  3. 点按“检查”，即会显示按月统计和未找到的文件列表。
  • 未找到的文件可通过“导入未找到的 N 个…”直接导入。
  • 报告可保存为 PDF 或 CSV。
  • Mac 文件夹和 SD 卡可选择“比较内容（严格检查）”，连改了名称的副本和损坏的副本也能找到。

8. 使用 iCloud 照片的用户请注意

在 iPhone 上删除照片，也会从 iCloud 及使用同一 Apple 账户的所有设备中删除。即使遗漏检查显示“已全部保存”，也请注意这一点。

  • 如果 iPhone 开启了 iCloud 照片和“优化 iPhone 储存空间”，部分照片的原片仅存于 iCloud。这些照片无法通过数据线导入（这是 Apple 的机制）。连接时，本 App 会检查是否开启了 iCloud 照片并通知您。
  • 这些照片可在使用同一 Apple 账户并开启 iCloud 照片的 Mac 上，通过“从照片图库导入”导入。原片会通过“照片”App 自动下载（无需手动下载或使用 iPhone；需要网络连接，照片较多时会花费一些时间）。
  • 如果此 Mac 未开启 iCloud 照片，iCloud 中的照片不在图库中，因此无法导入。

9. 免费版与 Pro

即使是免费版，读取、查看内容、试运行、查找重复项、遗漏检查、撤销、继续导入也均无限制。

  • 免费版：导入与整理所有操作合计每天最多 100 个。超过今天的剩余数量时，可选择“仅导入今天剩余的 N 个”。第二天重复相同操作即可继续导入。
  • Pro：无限制导入，合并与删除重复项，保存报告（PDF、CSV），“导入剩余部分”。

Pro 为一次买断（无月费），支持家人共享。可从画面右上角的“升级到 Pro”购买。在其他 Mac 上或重新安装后，请在菜单栏中选择“KuraPhoto › 恢复购买”。

10. 语言与详细模式

  • 语言：通常以 Mac 的语言显示（中文、英语、德语、法语、日语、韩语）。如只想让此 App 使用其他语言，请在“KuraPhoto › 设置…”（⌘,）中选择，然后点按“重新启动并切换”。
  • 详细模式：面向熟练用户，可在一个画面中完成所有设置。从主页底部打开。

11. 安全机制

  • 不会删除来源中的照片。没有彻底删除的功能。
  • 复制时先写入临时文件，完成后再命名，因此即使中途停止也不会留下损坏的文件。
  • 名称相同但内容不同的文件不会被覆盖，会添加“_1”等后两者都保留。
  • 保存位置空间即将不足时会安全停止。腾出空间后执行相同操作即可继续。
  • 处理记录（日志）保存在保存位置的“KuraPhoto 日志”文件夹中。除了导入与整理，合并或删除重复项以及“撤销”也会记录。日志在 3 年后会自动删除。
  • 保存位置和整理过的文件夹中，会生成用于“撤销”和“继续导入”的隐藏文件夹（名称以“.KuraPhoto-”开头）。请勿删除，否则将无法撤销此前的整理。

12. 疑难解答

iPhone 不显示／照片为 0 个

请解锁并选择“信任”后重新选择。更换数据线或 USB 扩展坞有时会改善。

Android 不显示

请在通知的“USB 设置”中选择“传输照片（PTP）”。

导入非常慢

iPhone 的传输速度取决于 USB 连接。请不要使用扩展坞，直接连接到 Mac 的 USB 端口。保存位置为 USB 硬盘时也会比较慢。

中途数据线松脱或停止

重新连接后，主页会显示“继续导入”。

保存位置空间不足

会安全停止，此前的部分已经保存。腾出空间或选择其他保存位置后执行相同操作，将跳过已保存的部分并继续。

无法访问文件夹或保存位置

出于 Mac 的保护机制，KuraPhoto 只能读写您亲自选择的文件夹。出现提示时，请重新选择该文件夹。如果是外置磁盘，请确认已连接。

照片图库显示 0 个

请在“系统设置 › 隐私与安全性 › 照片”中，将 KuraPhoto 设为“完全访问”。如果“照片”App 是空的，则没有可导入的内容。

如仍未解决，请联系 kuraphoto@kurawise.com。我们通常会在 2–3 个工作日内回复。
