1. 入門：基本流程

在主頁選擇「想做什麼」後，每個畫面只顯示一個步驟的說明。只需按一下「下一步」即可完成。

  1. 選擇來源（iPhone、SD 卡、資料夾等）
  2. 確認內容（全部匯入，或查看內容後選擇）
  3. 選擇儲存位置資料夾（也可選擇上次的儲存位置）
  4. 選擇資料夾的劃分方式（年 / 月、年 / 月 / 日、含地名）
  5. 確認後開始。使用「試行」，可以不實際拷貝、僅查看結果
已匯入的照片會自動略過，同一裝置多次匯入也不會重複。匯入完成後，會自動檢查來源中的照片是否已全部儲存到儲存位置，並在完成畫面頂部顯示結果。

處理期間 Mac 不會進入睡眠，同時也可以使用其他 App。完成後會透過通知告知您。

2. 從 iPhone 或 iPad 匯入

  1. 用連接線將 iPhone 連接到 Mac，並解鎖。
  2. 出現「要信任這部電腦嗎？」時，選擇「信任」。
  3. 選擇顯示的 iPhone 即可讀取內容，同時會顯示與儲存位置相比「未匯入 N 個」。
  • 原況照片（照片與影片的組合）和編輯資訊（.AAE）會原樣匯入。
  • 如需以 HEIC 格式匯入，請將 iPhone 的「設定 › App › 照片 › 傳輸到 Mac 或 PC」設為「保留原始檔案」。
  • 即使連接線鬆脫，重新連接後也可透過「繼續匯入」繼續。導致多次中斷的檔案會被自動取消選擇。
  • 照片較多時需要一些時間。不透過 USB 集線器、直接連接 Mac 會更快更穩定。

3. 從外部儲存裝置匯入

裝置連接方法與注意事項
SD、microSD、CF 卡插入讀卡機（microSD 請使用轉接卡）。讀取期間請勿拔出。
數位相機取出 SD 卡並用讀卡機讀取最快也最可靠。如透過 USB 連接，請開啟相機電源，並將 USB 模式設為「PC 連接」「PTP」等。
Android 手機透過 USB 連接並解鎖手機，在通知的「USB 設定」中選擇「傳輸照片（PTP）」。「檔案傳輸」模式下 Mac 無法辨識。僅存在於 Google 相簿中的照片無法匯入，請先儲存到手機。
USB 隨身碟、外接磁碟直接連接即可。支援 APFS、Mac OS 擴充格式、exFAT、FAT32、NTFS（唯讀）。
NAS、網路資料夾先在 Finder 中連接，再透過「選擇其他位置…」選擇。

拔出前，請先在 Finder 中按一下「退出」。

支援的檔案格式

  • 照片：HEIC、JPEG、PNG、TIFF、GIF、WebP、AVIF、JPEG XL，以及主流相機的 RAW（DNG、CR2/CR3、NEF、ARW、RAF、ORF、RW2、PEF、SRW、3FR、IIQ 等）
  • 影片：MOV、MP4、M4V、3GP、AVI、MTS/M2TS、MKV、WebM、MPG、WMV、MXF 等
  • 一併處理的附屬檔案：iPhone 的編輯資訊（.AAE）、Lightroom 等的沖印設定（.XMP）。會與同名照片一起拷貝或移動

拍攝日期從照片的 Exif 和影片的拍攝日期中讀取。無法讀取的格式，將使用檔案建立日期與修改日期中較早的一個。

4. 整理 Mac 資料夾

  • 拷貝並整理（推薦）：依「年/月」拷貝到其他資料夾。原始檔案保持不變。
  • 在此資料夾內整理：在該資料夾內移動到「年/月」資料夾，不會增加佔用空間。之後可透過「還原」（⌘Z）恢復整理前的狀態。

「照片」App 的圖庫請使用「從照片圖庫匯入」。

5. 從照片圖庫匯入

將 Mac「照片」App 中的照片和影片原始檔匯出到一般資料夾並整理。首次使用時會詢問是否允許取用照片圖庫，請選擇「允許」。

  • 不會更改或刪除圖庫中的照片。
  • 編輯過的照片可選擇「僅原始檔」「僅編輯後」或「兩者」。也可以依相簿選擇。
  • 原始檔僅存於 iCloud 的照片，會在匯入時透過「照片」App 自動下載（了解詳情）。

6. 重複檢查

選擇資料夾後，會尋找相同的照片以及僅大小或格式不同的副本。尋找方式可選「完全相同」「幾乎相同」（轉換或縮小的副本）「相似照片」（連拍等）。

  • ⭐ 表示建議「保留的那一張」（畫質最好的）。按一下即可更改。
  • 合併：將保留的那一張以外的照片移到「重複檔案」資料夾。刪除：移到垃圾桶。
  • 兩種方式之後都可以透過「還原」放回原處。

7. 遺漏檢查

按月檢查所連接裝置中的照片和影片是否已全部匯入儲存位置，並產生報告。推薦在從 iPhone 刪除照片前用作備份檢查。僅檢查，不會更改任何檔案。

  1. 打開主頁中的「遺漏檢查」。
  2. 選擇要檢查的裝置和儲存位置（匯入的資料夾）。
  3. 按一下「檢查」，即會顯示按月統計和未找到的檔案列表。
  • 未找到的檔案可透過「匯入未找到的 N 個…」直接匯入。
  • 報告可儲存為 PDF 或 CSV。
  • Mac 資料夾和 SD 卡可選擇「比較內容（嚴格檢查）」，連改了名稱的副本和損毀的副本也能找到。

8. 使用 iCloud 照片的使用者請注意

在 iPhone 上刪除照片，也會從 iCloud 及使用同一 Apple 帳號的所有裝置中刪除。即使遺漏檢查顯示「已全部儲存」，也請注意這一點。

  • 如果 iPhone 開啟了 iCloud 照片和「最佳化 iPhone 儲存空間」，部分照片的原始檔僅存於 iCloud。這些照片無法透過連接線匯入（這是 Apple 的機制）。連接時，本 App 會檢查是否開啟了 iCloud 照片並通知您。
  • 這些照片可在使用同一 Apple 帳號並開啟 iCloud 照片的 Mac 上，透過「從照片圖庫匯入」匯入。原始檔會透過「照片」App 自動下載（無需手動下載或使用 iPhone；需要網路連線，照片較多時會花費一些時間）。
  • 如果此 Mac 未開啟 iCloud 照片，iCloud 中的照片不在圖庫中，因此無法匯入。

9. 免費版與 Pro

即使是免費版，讀取、查看內容、試行、尋找重複項目、遺漏檢查、還原、繼續匯入也均無限制。

  • 免費版：匯入與整理所有操作合計每天最多 100 個。超過今天的剩餘數量時，可選擇「僅匯入今天剩餘的 N 個」。隔天重複相同操作即可繼續匯入。
  • Pro：無限制匯入，合併與刪除重複項目，儲存報告（PDF、CSV），「匯入剩餘部分」。

Pro 為一次買斷（無月費），支援家人共享。可從畫面右上角的「升級到 Pro」購買。在其他 Mac 上或重新安裝後，請在選單列中選擇「KuraPhoto › 回復購買項目」。

10. 語言與詳細模式

  • 語言：通常以 Mac 的語言顯示（中文、英文、德文、法文、日文、韓文）。如只想讓此 App 使用其他語言，請在「KuraPhoto › 設定…」（⌘,）中選擇，然後按一下「重新啟動並切換」。
  • 詳細模式：適合熟練使用者，可在一個畫面中完成所有設定。從主頁底部打開。

11. 安全機制

  • 不會刪除來源中的照片。沒有徹底刪除的功能。
  • 拷貝時先寫入暫存檔，完成後再命名，因此即使中途停止也不會留下損毀的檔案。
  • 名稱相同但內容不同的檔案不會被覆寫，會加上「_1」等後兩者都保留。
  • 儲存位置空間即將不足時會安全停止。騰出空間後執行相同操作即可繼續。
  • 處理記錄儲存在儲存位置的「KuraPhoto 記錄」資料夾中。除了匯入與整理，合併或刪除重複項目以及「還原」也會記錄。記錄在 3 年後會自動刪除。
  • 儲存位置和整理過的資料夾中，會產生用於「還原」和「繼續匯入」的隱藏資料夾（名稱以「.KuraPhoto-」開頭）。請勿刪除，否則將無法還原先前的整理。

12. 疑難排解

iPhone 不顯示／照片為 0 個

請解鎖並選擇「信任」後重新選擇。更換連接線或 USB 集線器有時會改善。

Android 不顯示

請在通知的「USB 設定」中選擇「傳輸照片（PTP）」。

匯入非常慢

iPhone 的傳輸速度取決於 USB 連接。請不要使用集線器，直接連接到 Mac 的 USB 埠。儲存位置為 USB 硬碟時也會比較慢。

中途連接線鬆脫或停止

重新連接後，主頁會顯示「繼續匯入」。

儲存位置空間不足

會安全停止，先前的部分已經儲存。騰出空間或選擇其他儲存位置後執行相同操作，將略過已儲存的部分並繼續。

無法取用資料夾或儲存位置

基於 Mac 的保護機制，KuraPhoto 只能讀寫您親自選擇的資料夾。出現提示時，請重新選擇該資料夾。如果是外接磁碟，請確認已連接。

照片圖庫顯示 0 個

請在「系統設定 › 隱私權與安全性 › 照片」中，將 KuraPhoto 設為「完整取用權限」。如果「照片」App 是空的，則沒有可匯入的內容。
